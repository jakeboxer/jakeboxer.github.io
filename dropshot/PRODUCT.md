# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Mac users receiving iPhone photos in Messages who need an image they can paste into other apps.
## Product Purpose
A static download page for Dropshot, a macOS menu bar utility converting one dragged HEIC to clipboard image content.
## Capabilities and Constraints
Drop into the zone under the menu bar icon for JPEG; hold Option when dropping for PNG. Current app targets macOS 26.5 and Apple silicon. A public download asset has not been verified; the existing page says downloads are coming later.
## Brand Commitments
Blue-led techno rave aesthetic, deliberately excessive for a small utility. Deadpan rave hype. Follow-up direction: deliberately jankier and homemade, with crooked cut-and-paste composition and mismatched typography. Hypnotic motion without flashing or audio; respect reduced motion.
## Evidence on Hand
Sibling Dropshot repository provides behavior, deployment target, and icon blue #007AFF. Existing site is static HTML served by GitHub Pages, with no build dependencies.
